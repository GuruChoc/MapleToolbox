# Maple Toolbox v0.23 Public Beta

**One Toolbox to run them all.**

Maple Toolbox is a Windows control panel for the separate MapleStory Idle RPG tools.

## Public Beta baseline

### Workflow
1. Directory Health
2. System Requirements
3. GitHub Update Manager
4. Equipment Bag Screenshot Capture Tool
5. MapleOCR
6. ZIP Inspector
7. MapleForge
8. BISMIRPG

### GitHub Update Manager
The manager now checks **Maple Toolbox itself** as well as supported public-release modules.

Current tracked release sources:
- Maple Toolbox
- Equipment Bag Screenshot Capture Tool
- MapleOCR
- BISMIRPG

Private/unreleased modules such as MapleForge are shown separately and do not count as downloadable releases.

### Safety
- Nothing installs silently.
- Nothing updates silently.
- Prerequisite installs are shown in a visible terminal.
- Errors only are logged under `Errors\`.
- Failed runs stay open.
- Successful MapleOCR runs show live progress and auto-close after a visible countdown.
